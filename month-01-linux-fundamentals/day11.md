# Linux Day 11
## Topic
Special Permissions(SUID, SGID, Sticky Bit)

## What I Learned
 - SUID runs a program with the owner's privileges. 
 - SGID makes new files inherit the directory's group.
 - Sticky Bit protects files in shared directories.
 The 'passwd' command uses SUID to update '/etc/shadow' .

 ## Commands

 ls -l
 find
 chmod u+s
 chmod g+s
 chmod +t
