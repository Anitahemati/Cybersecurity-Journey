# Linux Day 10

## Topic
File Permissions

- chmod changes file permissions.
- Numeric permissions use r=4, w=2, x=1.
- Symbolic mode uses u, g, o, and a.
- chown changes the file owner.
- chgrp changes the file group.

## Commands

chmod
chown
chgrp
type
which
ls -l
