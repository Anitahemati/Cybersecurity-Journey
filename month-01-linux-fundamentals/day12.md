# Linux Day 12

## Topic
Processes & Process Management

## What I Learned

- A Program is the executable code, while a process is a running instance of a program.
- Every process has a unique PID.
- PPID identifies the parent process.
- Processes can have parent-child relationships.
- 'ps' and 'ps aux' can be used to inspect processes.
- 'pstree showes processes as a tree.
- 'top' monitors running processes.
- 'kill' sends a signal to a process.

## Commands

- ps
- ps aux
- ps -ef
- pstree
- top
- kill
